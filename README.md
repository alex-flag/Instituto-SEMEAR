# Instituto-SEMEAR

Projeto web com Vite+ (Vanilla JavaScript) e API Express com rota `/api/health`.

## Requisitos

- Git
- Vite+ (`vp`): https://viteplus.dev

## Como rodar o projeto

1. Clone o repositorio e entre na pasta:
   `git clone https://github.com/alex-flag/Instituto-SEMEAR.git`
   `cd Instituto-SEMEAR`
2. Instale as dependencias: `vp install`
3. Copie `.env.example` para `.env` e ajuste `PORT` se necessario (`3000` por padrao).
4. Em um terminal, inicie a API: `vp run api`
5. Em outro terminal, inicie o frontend: `vp dev`
6. Abra `http://localhost:5173` no navegador.
