# Instituto-SEMEAR

Projeto web com Vite+ (Vanilla JavaScript) e API Express com rota `/api/health`.

## Como rodar o projeto

1. Instale as dependencias: `npm install`
2. Copie `.env.example` para `.env` e ajuste `PORT` se necessario (`3000` por padrao).
3. Em um terminal, inicie a API: `vp run api`
4. Em outro terminal, inicie o frontend: `vp dev`
